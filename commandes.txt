TP8 - Benchmark des tas min en C++
==================================

Fichier source : benchmark_heap.cpp
Fichier de resultats : output.txt (cree automatiquement dans le dossier courant)

Compilation avec MinGW / g++ :
    g++ -std=c++17 -O2 -Wall -Wextra -pedantic benchmark_heap.cpp -o benchmark_heap.exe

Execution dans PowerShell :
    .\benchmark_heap.exe

Execution depuis l'invite de commandes Windows :
    benchmark_heap.exe

Fonctionnement :
- Le programme compare quatre tas min : implementation maison sur vector,
  list et map, et implementation STL sur vector avec push_heap, pop_heap et
  make_heap.
- Le menu insere, recherche ou supprime une valeur dans les quatre tas.
- Le choix 4 supprime le minimum de chaque tas.
- Le choix 5 ecrit les tas courants dans output.txt.
- Le choix 6 demande N, genere N valeurs aleatoires identiques et mesure
  uniquement l'insertion et l'extraction de tous les minimums.
- Jusqu'a 5000 elements, le benchmark mesure les quatre variantes. Au-dela,
  il mesure seulement les tas maison/vector et STL/vector.
- Les resultats du benchmark remplacent le contenu precedent de output.txt.
- N doit etre compris entre 0 et 1000000. Les variantes list et map sont
  ignorees au-dela de 5000 elements en raison du cout de leurs acces par indice.

Remarque :
La variante STL utilise les algorithmes de tas de la bibliotheque standard sur
un vector. Les recherches et suppressions interactives par valeur sont ajoutees
pour offrir les memes operations dans le menu. L'extraction du benchmark est
le retrait repete du minimum jusqu'a vider le tas.
