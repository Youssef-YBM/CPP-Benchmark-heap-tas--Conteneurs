TP8 - Benchmark des tas min et max en C++
========================================

Fichier source : benchmark_heap.cpp
Fichier de resultats : output.txt (cree automatiquement dans le dossier courant)
Rapport tas min : rapport_benchmark.tex
Rapport tas max : rapport_tas_max.tex
Mesures : benchmark_mesures_brutes.csv et benchmark_resultats.csv

Compilation avec MinGW / g++ :
    g++ -std=c++17 -O2 -Wall -Wextra -pedantic benchmark_heap.cpp -o benchmark_heap.exe

Execution dans PowerShell :
    .\benchmark_heap.exe

Execution depuis l'invite de commandes Windows :
    benchmark_heap.exe

Menu :
- Les choix 1 a 3 inserent, recherchent ou suppriment une valeur dans les huit tas :
  tas min et max maison sur vector, list et map, et tas STL sur vector.
- Le choix 4 extrait simultanement le minimum et le maximum.
- Le choix 5 ecrit les huit tas dans output.txt.
- Le choix 6 compare l'insertion et l'extraction complete avec les memes valeurs
  aleatoires pour les implementations d'un meme essai.

Benchmark :
- La saisie accepte N entre 0 et 1000000000 (10^9).
- Le programme controle la memoire physique disponible avant l'allocation.
  Il estime environ 2 * N * sizeof(int), plus une marge de 512 Mio. Une saisie
  autorisee ne garantit donc pas que le test soit executable sur l'ordinateur.
- Les tas vector maison et STL sont testes pour toutes les tailles.
- Les tas maison sur list et map sont ajoutes seulement si N <= 5000, car
  l'acces indexe est couteux pour ces conteneurs.
- Les temps d'insertion incluent la reservation de capacite du vector.
  La generation aleatoire et l'ecriture du fichier ne sont pas chronometrees.
- L'extraction mesure le retrait de toutes les racines jusqu'a vider le tas.
- Le benchmark remplace le contenu precedent de output.txt.

Les rapports LaTeX se compilent separement avec une installation comprenant
pdflatex et PGFPlots :
    pdflatex rapport_benchmark.tex
    pdflatex rapport_tas_max.tex

Les tableaux et graphiques reprennent les tailles pour lesquelles des mesures
sont conservees, jusqu'a 100 millions d'elements. Les valeurs a 100 millions
proviennent d'une seule execution.
